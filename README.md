# LockByte

LockByte is a command-line file encryption tool. It takes any file and a user password, then outputs an encrypted file that only the correct password can unlock.

## Installation Req

pip install pycryptodome

## Usage

## Usage

**Encrypt:**
1. Run `python encrypt.py`
2. Enter file to encrypt
3. Enter output name
4. Enter password

**Decrypt:**
1. Run `python decrypt.py`
2. Enter encrypted file
3. Enter output name
4. Enter password
