# LockByte

A tool encrypt any file with only a password. 
Using AES-256-CBC + SHA-256 stretching (10,000 iterations) + HMAC-SHA256 algorithms.

## Installation Req

pip install pycryptodome

## Usage

## Usage

**Encrypt:**
1. Run `python encrypt.py`
2. Enter file to encrypt
3. Enter output name
4. Enter password

**Decrypt:**
1. Run `python decrypt.py`
2. Enter encrypted file
3. Enter output name
4. Enter password
